TonePush 0.9.1 moves the Windows installer to a Windows Installer package (`.msi`), because antivirus engines flag the old setup program. If you installed TonePush with the 0.9.0 setup program, **Update** brings you 0.9.1 through that setup program as before, and the update after it moves you onto the new installer by itself, in the same folder and with your settings.

## New

- **A Windows Installer package for x64 and ARM.** Like the setup program, it installs for you alone without administrator rights, adds TonePush to the Start menu and installs the `tonepush` command-line tool. Installed over a copy from the 0.9.0 setup program, it takes that copy's place: same folder, its desktop shortcut kept, one entry in Settings, Apps. From 0.9.1 on, updates from inside TonePush use it. By @crmne.

## Fixed

- **Uninstalling while TonePush runs no longer leaves half of it behind.** The new installer, and the uninstaller of this release's setup program, wait until TonePush and any `tonepush` command have quit. By @crmne.
- **TonePush uses less memory for the fonts it falls back on** for scripts Inter does not cover. By @crmne.

## Known limitations

- This release still includes the setup programs (`-setup.exe`), so that copies of 0.9.0 can update; later releases ship the `.msi` only. A copy unpacked from the Windows zip keeps updating as a zip.
- The installer never closes TonePush for you; it asks you to quit it first.
- An HX Effects backup can still time out while reading the pedal's settings (#9), and an HX Stomp on firmware 3.80 that stays on "transferring data" (#5) is still being investigated.
